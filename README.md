# math-nuclear-engine
Программный комплекс для математического моделирования нестабильности и динамики реактора РБМК-1000.

## О проекте
Данный проект представляет собой симулятор активной зоны ядерного реактора, сфокусированный на воспроизведении физических аномалий доаварийного РБМК-1000 (положительный паровой коэффициент реактивности, эффекты Доплера и вытеснителей СУЗ). Расчет мощности и температурных режимов построен на численных методах интегрирования (схема Эйлера).

## Стек технологий
- Python 3
- Threading & Queue (асинхронный просчет физики и ввода)
- SQL / SQLite (в разработке — логирование телеметрии "черного ящика")
- GUI (в разработке)
